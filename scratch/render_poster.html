Zero-Trust Go Context In-Memory Privacy
Tokenizes real SSNs and emails in-memory with regex patterns, mapping tokens within r.Context(). Unmasks on HTTP response return. Zero persistence to disk or Redis (HIPAA/GDPR compliant).
ML
Python FastAPI ML Sidecar Embeddings & NER
Stateless microservice on :8000 computing dense vector embeddings and title-case entity extraction. The actual semantic cache similarity decision logic runs in Go for sub-millisecond execution.
RB
MCP Policy Engine Tool RBAC Firewall
Intercepts upstream model tool_calls payloads mid-air before agent execution. Validates team permissions against rbac/policies.json and drops rogue operations (e.g. drop_database) with 403 Forbidden.
SG
Streaming Guillotine In-Flight Socket Kill
Scans SSE tokens character-by-character in-flight. On detecting hallucination loops or banned leak patterns ([TOP_SECRET_PROJECT_X]), severs the upstream TCP socket instantly via context.CancelFunc (HTTP 451).
LG
Single-Writer Async Ledger Thread-Safe JSONL
Non-blocking buffered Go channel (10,000 capacity) paired with a dedicated worker goroutine that writes sequential audit records into audit_logs.jsonl with zero latency overhead.
